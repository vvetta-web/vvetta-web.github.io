# vvetta-web.github.io — КОФЕ & БЕТОН

Личная страница GitHub Pages. Размещены два сайта кофейни «КОФЕ & БЕТОН» (Москва, Мясницкая ул., 13, стр. 2):

- **Корень** (`/`) — постер-версия: бумага `#f4f1ea`, чернила `#141310`, красный `#e3361f`, Instrument Serif + Space Grotesk.
- **`/brutalism/`** — оригинальная бруталистская версия: чёрный/белый/кислотный `#D9FF00`, Archivo Black + Space Mono.

Оба сайта статические: `index.html` + `images/`, без бэкенда и внешних зависимостей, кроме Google Fonts. CSP задан meta-тегом.

Исходные репозитории: [kofebeton](https://github.com/vvetta-web/kofebeton) и [kofebeton-brutalism](https://github.com/vvetta-web/kofebeton-brutalism).
