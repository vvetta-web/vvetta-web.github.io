# vvetta-web.github.io — портфолио демо-сайтов

Личная страница GitHub Pages. Размещены демо-сайты для портфолио:

- **Корень** (`/`) — «КОФЕ & БЕТОН», кофейня (Москва): постер-версия, бумага `#f4f1ea`, чернила `#141310`, красный `#e3361f`, Instrument Serif + Space Grotesk.
- **`/brutalism/`** — «ДВАВОСЕМЬ», эспрессо-бар (Санкт-Петербург): брутализм, чёрный/белый/оранжевый `#FF4D00`, Montserrat Black + IBM Plex Mono.
- **`/raya/`** — «RAYA», демо-сайт бренда солнцезащитных очков.

Все сайты статические: `index.html` + `images/`, без бэкенда и внешних зависимостей — шрифты подключены локальными файлами woff2. CSP задан meta-тегом.

Исходные репозитории: [kofebeton](https://github.com/vvetta-web/kofebeton) и [kofebeton-brutalism](https://github.com/vvetta-web/kofebeton-brutalism).
